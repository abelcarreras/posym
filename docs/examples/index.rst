Example Scripts
---------------

Additional example scripts can be found in the ``examples/`` directory
of the source repository:

- `geometric_symmetry.py <https://github.com/abelcarreras/posym/blob/master/examples/geometric_symmetry.py>`_ — Molecular geometry CSM
- `normal_modes.py <https://github.com/abelcarreras/posym/blob/master/examples/normal_modes.py>`_ — Normal mode symmetry analysis
- `wf_single_determinant.py <https://github.com/abelcarreras/posym/blob/master/examples/wf_single_determinant.py>`_ — Single-determinant wave function
- `wf_multi_determinant.py <https://github.com/abelcarreras/posym/blob/master/examples/wf_multi_determinant.py>`_ — Multi-reference wave function
- `orbitals_pyscf.py <https://github.com/abelcarreras/posym/blob/master/examples/orbitals_pyscf.py>`_ — PySCF integration
