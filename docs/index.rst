PoSym Documentation
===================

**PoSym** is a point symmetry analysis tool written in Python designed for
theoretical chemistry. It uses continuous symmetry measures (CSM) to provide
a robust implementation for computing the symmetry of chemical objects such
as normal modes, wave functions, and electronic densities.

Key Features
------------

- Irreducible representation calculator supporting direct sum and product
- Continuous symmetry measures (CSM) in the basis of irreducible representations
- Symmetry determination of normal modes
- Symmetry of functions defined in Gaussian basis (orbitals, densities, operators)
- Wave function symmetry for single and multi-determinant states
- Autogenerated high-precision symmetry tables
- Compatible with PySCF and PyQchem

Supported Point Groups
----------------------

``Cs``, ``Ci``, ``C{n}``, ``C{n}v``, ``C{n}h``, ``D{n}``, ``D{n}h``,
``D{n}d``, ``I``, ``Ih``, ``O``, ``Oh``, ``S{n}``, ``T``, ``Td``, ``Th``

where ``{n}`` is any integer (e.g. ``C2v``, ``D6h``).
